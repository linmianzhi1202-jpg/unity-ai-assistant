# S8: Context Compactor — 上下文优化建议

## 用途

**定位**：对话上下文的瘦身顾问，提供压缩策略建议。

**核心价值**：
- **Token 预算管理**：估算当前上下文使用量
- **压缩策略建议**：提供三级压缩策略选择
- **关键信息保留**：确保压缩后保留核心信息

## 触发条件

| 触发方式 | 条件 | 动作 |
|----------|------|------|
| **用户请求** | "压缩上下文"/"compact context" | 提供压缩建议 |
| **命令触发** | `/compact` 命令 | 提供压缩建议 |
| **主动建议** | 对话轮次 >= 15 | 提示用户考虑压缩 |

**注意**：S8 仅提供建议，不自动执行压缩。实际压缩需要 CodeBuddy 平台支持。

## 核心能力

### 能力 1：Token 预算估算

基于 chars/4 规则估算上下文使用量：

```yaml
估算公式:
  tokens ≈ ceil(字符数 / 4)
  
上下文窗口配置:
  glm-4-plus: 128K tokens
  安全边界: 13K tokens (触发压缩建议的阈值)
  可用空间: 115K tokens
```

**使用率估算**：

```markdown
## 📊 Context Usage Estimation

**估算 Token**: {estimated:,} / {window:,}
**使用率**: {usage_pct}%
**状态**: 
- 🟢 安全 (< 70%)
- 🟡 接近上限 (70-85%)
- 🟠 需要压缩 (85-95%)
- 🔴 紧急压缩 (> 95%)
```

### 能力 2：三级压缩策略

| 级别 | 触发条件 | 压缩强度 | 保留内容 |
|------|----------|----------|----------|
| **L1 轻度** | 70-85% usage | 压缩最早 30% 历史 | 任务目标 + 最近决策 |
| **L2 中度** | 85-95% usage | 压缩 50% 历史 | 关键里程碑 + 当前任务 |
| **L3 重度** | > 95% usage | 仅保留摘要 | 核心目标 + 紧急待办 |

### 能力 3：9-Lane 行优先级压缩方法论

基于行分类器的压缩策略：

```yaml
line_priority:
  priority_0_core:
    description: "核心行：任务目标、里程碑、决策点"
    patterns:
      - "^#+.*(目标|任务|完成|决策|问题)"
      - "^#+ (TODO|DONE|BLOCKER)"
      - "^\\*\\*结果\\*\\*:"
    action: "始终保留"
  
  priority_1_section:
    description: "章节标题：## ### 分隔符"
    patterns:
      - "^#{1,6} .+"
      - "^---+$"
    action: "优先保留"
  
  priority_2_listitem:
    description: "列表项：- * 数字列表"
    patterns:
      - "^\\s*[-*+] .+"
      - "^\\s*\\d+\\. .+"
    action: "选择性保留"
  
  priority_3_other:
    description: "其他：普通文本"
    patterns:
      - ".+"
    action: "压缩时优先丢弃"
```

### 能力 4：压缩建议清单

用户请求压缩时，提供以下建议：

```markdown
## 🗜️ Context Compaction Recommendation

### 当前状态
- 估算 Token: {estimated:,} / {window:,}
- 使用率: {usage_pct}%
- 建议级别: {level}

### 压缩策略建议
**策略**: {level_name}
**预期效果**: 释放 ~{freed_tokens:,} tokens
**保留内容**: {preserved_elements}

### 压缩方法论
1. **识别可压缩内容**：
   - 早期对话的详细探索过程
   - 重复的确认和解释
   - 已完成任务的历史记录

2. **保留关键信息**：
   - 任务目标和里程碑
   - 重要决策和理由
   - 当前任务的上下文
   - 关键文件引用

3. **压缩后恢复点**：
   - 最近编辑的文件（建议重新读取）
   - 激活的技能（建议重新加载）
   - 活跃的计划（建议重新加载）

### 执行建议
⚠️ **注意**: 实际压缩需要 CodeBuddy 平台支持。
建议用户：
- 手动总结当前进度
- 重新开始新会话（带摘要）
- 使用 `/compact` 命令（如果平台支持）
```
