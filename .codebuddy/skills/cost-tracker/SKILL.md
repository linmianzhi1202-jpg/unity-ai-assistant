# S7: Cost Tracker — 成本估算与优化建议

## 用途

**定位**：成本意识专家，帮助用户了解会话资源消耗。

**核心价值**：
- **成本透明**：估算当前会话的 Token 消耗和成本
- **预算预警**：提供四级预算阈值提醒
- **优化建议**：基于使用模式生成优化建议

## 触发条件

| 触发方式 | 场景 |
|----------|------|
| **用户显式请求** | "看看花了多少"、"cost report"、"费用" |
| **命令集成** | `/status` 或 `/status detail` 自动附带成本段 |
| **手动检查** | 定期自我评估（如每 10 轮对话） |

## 核心能力

### 能力 1：会话成本估算

基于 GLM-4 Plus 定价估算当前会话成本：

```yaml
定价表:
  glm-4-flash: $0.00/M (免费)
  glm-4-air: $0.14/M
  glm-4-plus: $0.69/M ← 默认
  glm-4-long: $0.56/M
  glm-4: $1.39/M

估算公式:
  input_tokens ≈ ceil(输入字符数 / 4) + 1
  output_tokens ≈ ceil(输出字符数 / 4) + 1
  total_tokens = input + output
  cost_usd = total_tokens * 0.69 / 1_000_000
```

**成本量级参考**：
```yaml
典型场景:
  小型会话: < 100K tokens → $0.069
  中型会话: 100K-500K tokens → $0.069-$0.345
  大型会话: 500K-1M tokens → $0.345-$0.69
  超大会话: > 1M tokens → > $0.69
```

### 能力 2：四级预算预警

```yaml
budget_thresholds:
  normal: "< $0.50"    # 绿色：正常使用
  notice: "$0.50 ~ $1.00" # 黄色：轻度提醒
  warning: "$1.00 ~ $5.00" # 橙色：中度警告
  alert: "> $5.00"       # 红色：重度警告
```

**预警输出格式**：

```markdown
## 💰 Cost Estimation Report

**定价模型**: GLM-4 Plus ($0.69/M)
**估算 Token**: {total_tokens:,}
**估算成本**: **${total_cost_usd:.4f}**

### 预算状态
{根据阈值显示对应状态}
- 🟢 正常范围 (< $0.50)
- 🟡 接近预算 ($0.50-$1.00)
- 🟠 超出预算 ($1.00-$5.00)
- 🔴 严重超预算 (> $5.00)

### 操作分布估算
| 类型 | 估算次数 | 占比 |
|------|---------|------|
| 读操作 | ... | ...% |
| 搜索 | ... | ...% |
| 编辑 | ... | ...% |
| 写入 | ... | ...% |
| 命令 | ... | ...% |
```

### 能力 3：优化建议引擎

基于使用模式自动生成建议：

| 模式 | 条件 | 建议 |
|------|------|------|
| **高频搜索** | search 类占比 > 40% | 缩小搜索范围、使用更精确的模式 |
| **冗余读取** | 同一文件 read >= 3 次 | 后续只读变更部分 |
| **慢操作** | 存在 >10s 命令 | 检查是否卡住、拆分为小命令 |
| **低效率** | 均/次 > $0.003 且调用 > 30 | 减少大文件全读 |
| **编辑密集** | edit+write 占比 > 50% | 确认每次编辑必要性 |

### 能力 4：成本优化检查清单

用户请求成本优化时，执行以下检查：

```markdown
## 📋 Cost Optimization Checklist

### 1. 操作效率
- [ ] 是否有重复读取同一文件？
- [ ] 是否可以合并多次搜索为一次？
- [ ] 是否有不必要的完整文件输出？

### 2. Token 消耗
- [ ] 是否有大段重复内容输出？
- [ ] 是否可以更精简地表达结果？
- [ ] 是否有冗长的确认和解释？

### 3. 调用模式
- [ ] 是否使用了最合适的工具（如 search vs read）？
- [ ] 是否有可以批量处理的操作？
- [ ] 是否有不必要的重试？

### 💡 优化建议
{基于检查结果生成的 1-3 条具体建议}
```

## 输出规范

| 场景 | 输出级别 | 内容 |
|------|---------|------|
| "多少钱" | L1 单行 | `$X.XXXX USD (估算 T tokens)` |

| "成本优化" | L3 详细 | L2 + 优化检查清单 + 建议 |
