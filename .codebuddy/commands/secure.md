# /secure - 安全扫描快捷命令

## 功能说明

触发 `security-scanner` 代理对当前项目进行 OWASP Top 10 安全扫描。

## 使用方式

```
/secure [scan_type]
```

### 参数说明

- `scan_type` - 扫描类型（可选）
  - `full` - 全量扫描（默认）
  - `quick` - 快速扫描（只扫描高危漏洞）
  - `targeted` - 定向扫描（指定文件或目录）

## 执行流程

1. **调用 security-scanner 代理**
2. **执行 OWASP Top 10 扫描**：
   - A01:2021 - 失效的访问控制
   - A02:2021 - 加密失败
   - A03:2021 - 注入
   - A04:2021 - 不安全设计
   - A05:2021 - 安全配置错误
   - A06:2021 - 易受攻击和过时的组件
   - A07:2021 - 识别和认证失败
   - A08:2021 - 软件和数据完整性故障
   - A09:2021 - 安全日志记录和监控失败
   - A10:2021 - 服务器端请求伪造（SSRF）

3. **生成安全报告**
4. **提供修复建议**

```markdown

**扫描类型**：`{scan_type}`

**检测结果**：
| 严重等级 | 数量 |

| 低危 | 3 |

### A01:2021 - 失效的访问控制
- [ ] 无未授权访问风险
- [ ] 无权限提升风险

**检测结果**：
| 严重等级 | 数量 |
|----------|------|
| 高危 | 1 |
| 中危 | 3 |

... (其他 A01-A10 类似格式)

## 二、漏洞详情

### P0 - 高危漏洞

#### 1. A03:2021 - SQL 注入（第 128 行）

**描述**：字符串拼接 SQL，有 SQL 注入风险

**代码**：
```python
# 错误示例
cursor.execute(f"SELECT * FROM users WHERE id = {user_id}")
```

**修复建议**：
```python
# 正确示例
cursor.execute("SELECT * FROM users WHERE id = %s", (user_id,))
```

**修复优先级**：P0（必须立即修复）

### P1 - 中危漏洞

#### 2. A01:2021 - 未授权访问（第 42 行）

**描述**：用户 ID 未验证，可能访问其他用户数据

**修复建议**：添加用户身份验证和授权检查

**修复优先级**：P1（应该修复）

## 三、综合评估

- **安全评分**：4/10
- **高危漏洞**：3 个
- **中危漏洞**：5 个
- **低危漏洞**：3 个

## 四、修复建议

1. [P0] 修复 SQL 注入（第 128 行）
2. [P0] 移除硬编码 API Key（第 200 行）
3. [P1] 添加用户 ID 验证（第 42 行）
4. [P2] 禁用调试模式（生产环境）
```
